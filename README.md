# Data Science Configurations
Configuration files for setting up data science environments using Conda, Mamba, Pip, and Docker. It includes environments for common workflows like JupyterLab, machine learning, and GPU-accelerated computations.

## Contents
- **`environments/`**: Conda/Mamba environment YAML files.
- **`pip/`**: Pip-based `requirements.txt` files for virtualenv setups.
- **`docker/`**: Dockerfiles for containerized workflows.
- **`scripts/`**: Bash scripts to automate environment management.
